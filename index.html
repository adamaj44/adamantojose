Linux Memory Injection PoC (Shared Object Injection & Memory Forensics)

Linux LD_PRELOAD gcc strace Memory Forensics

Built a benign shared-object (.so) injection lab on Kali Linux to study how LD_PRELOAD loads a library into a running process's memory space, then performed forensic analysis on the resulting memory mappings. Used /proc/[PID]/maps to identify the file-backed executable mapping left by the injected library, and strace to trace the openat() and mmap() syscalls the dynamic linker makes at load time. Also tested detection of anonymous (non-file-backed) executable memory regions to compare forensic artifacts between file-backed and shellcode-style injection techniques — a defensive-research exercise in what injected modules actually look like in memory.
